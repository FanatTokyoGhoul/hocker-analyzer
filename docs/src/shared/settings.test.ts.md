# `src/shared/settings.test.ts`

- Пустые или битые данные дают настройки по умолчанию.
- Числа вне диапазона ограничиваются, неизвестные режимы и неверный цвет заменяются умолчаниями.
- Корректные значения сохраняются; HEX приводится к `#rrggbb`; мусор в недавних цветах отбрасывается, повторы склеиваются (`#123` = `#112233`).
- `normalizeHex`: короткая форма, без `#`, неверная длина, `rgb(...)`.
- `pushRecentColor`: без повторов, без пресетов, не больше 8.
- Кнопки быстрой разметки: пустые подписи и лишние кнопки отбрасываются, лимит 9, пустой список сохраняется (его не подменяют стандартным набором), значения секунд ограничиваются.
