# `src/shared/project.ts` — проверка и сериализация JSON проекта

**Назначение:** безопасно прочитать файл проекта, который мог прийти от другого человека или быть повреждён. Поддерживает формат v2 (несколько видео, заметки, схемы, периоды) и читает v1 (одно видео в `videoPath`).

## Экспорт

| Функция | Описание |
|---|---|
| `parseProject(raw)` | Проверяет структуру, мелкие дефекты чинит, критичные — бросает `Error` с понятным текстом |
| `serializeProject(project)` | Пишет версию 2, `JSON.stringify(…, 2)` и перевод строки в конце. Поля `videoPath` и `fps` дублируют первое видео, их читают версии v1 |
| `parseShape(raw)` / `parseShapes(raw)` | Разбор одной фигуры или списка. Битые фигуры отбрасываются |
| `normalizePeriodStarts(periods)` | Только числа больше нуля, по возрастанию, без повторов |
| `PROJECT_VERSION` = 2, `MAX_TEXT_LENGTH` = 200 | |

## Видео

- **v2:** массив `videos`. Нет `id` → `v1`, `v2`…; повтор id получает `_`. Нет `label` → «Видео N». Нет `offset` → 0. `fps` без значения берётся из `fps` проекта, иначе 30. `duration` сохраняется, если положительный.
- **v1:** массив отсутствует, создаётся одно видео `{ id: 'v1', label: 'Видео 1', offset: 0 }` из `videoPath`.
- Видео без пути пропускается. Если видео не осталось и нет `videoPath`, это ошибка.

## Правила

- **Ошибка:** корень не объект; нет массива `moments`; нет видео; у момента нет числовых `start`/`end`.
- **Исправляется молча:**
  - перевёрнутый отрезок → `start`/`end` меняются местами, отрицательный `start` → 0;
  - нет `id` момента → генерируется; нет `title` → «Момент N»;
  - нечисловые теги отбрасываются;
  - `notes` сохраняется, только если не пустой;
  - рисунок на неизвестном `videoId` переезжает на первое видео (`videoId` не сохраняется);
  - рисунки и схема без фигур удаляются;
  - текст подписи обрезается до 200 символов.

Main вызывает `parseProject` при открытии, при записи черновика и перед сохранением, поэтому на диск не попадает ничего лишнего.
