# `src/shared/settings.ts` — настройки

**Назначение:** тип настроек, значения по умолчанию, проверка данных и работа с цветами. Это чистые функции, общие для main и renderer:
- main ([main/settings.ts](../main/settings.ts.md)) проверяет всё, что пишет в `settings.json`;
- renderer ([useSettings](../renderer/src/hooks/useSettings.ts.md)) проверяет каждое изменение.

## `Settings`

| Поле | По умолчанию | Смысл |
|---|---|---|
| `stepMs` | 100 | N для Shift+←/→, 1–60000 мс |
| `holdMode` | `'timer'` | Кадр с рисунком: `'off'` — не останавливаться, `'key'` — до нажатия клавиши, `'timer'` — на N секунд |
| `holdSeconds` | 3 | N для режима `'timer'`, 0.5–60 с (округление до 0.1) |
| `holdScope` | `'always'` | Где останавливаться: при любом просмотре или только в «Проиграть все» |
| `color` | `#ff3b30` | Текущий цвет рисования |
| `recentColors` | `[]` | До 8 последних цветов, которыми действительно рисовали (пресеты не входят) |
| `quickTags` | 6 кнопок | Кнопки быстрой разметки, до 9 |

## Кнопки быстрой разметки (`QuickTag`)

```ts
type QuickTag = { id: string; label: string; tag: string; before: number; after: number }
```

- `label` — подпись кнопки и основа названия момента («Гол 1»).
- `tag` — тег, который получит момент.
- `before`, `after` — секунды до и после текущего времени, 0–120, с шагом 0.1.
- По умолчанию: Гол (8 / 3), Бросок (5 / 2), Потеря (5 / 3), Отбор (4 / 3), Вбрасывание (2 / 5), Большинство (5 / 10).

Клавиша — `Shift+1…9` по порядку кнопок. Больше `MAX_QUICK_TAGS` = 9 кнопок не сохраняется.

При очистке (`sanitizeQuickTags`): пустая подпись → кнопка удаляется; пустой тег → подпись в нижнем регистре; повторы `id` получают `_`; подпись до 40 символов.

## Функции

| Имя | Описание |
|---|---|
| `PRESET_COLORS` | 8 базовых цветов меню рисования |
| `normalizeHex(s)` | `'#ABC'`, `'abc'`, `'#aabbcc'` → `'#aabbcc'`; всё остальное → `null` |
| `pushRecentColor(list, c)` | Добавляет цвет в начало без повторов; пресеты не добавляются; длина ≤ 8 |
| `sanitizeSettings(raw)` | Любое значение (битое, от старой версии) → корректные `Settings`. Числа ограничиваются, неизвестные режимы заменяются умолчаниями, неверные цвета отбрасываются, кнопки разметки чистятся |
| `DEFAULT_QUICK_TAGS`, `MAX_QUICK_TAGS` | Стандартный набор кнопок и лимит |

`sanitizeSettings` вызывается при чтении файла, при каждом изменении в интерфейсе и перед записью в main. Новое поле достаточно добавить сюда, и старые сохранённые настройки получат его значение по умолчанию.
