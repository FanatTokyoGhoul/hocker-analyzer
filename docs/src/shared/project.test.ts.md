# `src/shared/project.test.ts` — тесты формата проекта

| Тест | Что проверяет |
|---|---|
| Формат из брифа и round-trip | Пример с моментом «хорошая перепасовка» 78–85 с, тегом и стрелкой проходит без изменений; `serialize → parse` возвращает то же самое |
| Починка | Перевёрнутый отрезок 10→5, `fps` по умолчанию, заголовок по умолчанию, отброшенная неизвестная фигура |
| Отказ | `null`, нет `videoPath` и видео, момент без `start`/`end` |
| v2 | Несколько видео, заметки, схема, периоды, новые фигуры (`zone`, `text`, `spotlight`, пунктир) проходят round-trip; рисунок с неизвестным `videoId` переезжает на первое видео |
