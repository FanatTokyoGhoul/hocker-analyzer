# `src/renderer/src/hooks/useIdle.ts`

`useIdle(element, enabled, ms = 2500)` возвращает `true`, если пока `enabled` мышь над элементом не двигалась `ms` миллисекунд. Таймер сбрасывают движение мыши, нажатие и любая клавиша.

Используется для полноэкранного режима: пока видео играет, через 2.5 с бездействия панели управления, меню рисования и курсор плавно скрываются (класс `.is-idle`). На паузе `enabled = false`, и всё видно.
