# `src/renderer/src/hooks/useVideoClock.ts` — текущее состояние видео

**Назначение:** превращает `<video>` в React-состояние `{ time, paused, rate, duration }`, которое обновляется на каждом показанном кадре.

## Как работает

- Постоянный цикл `requestVideoFrameCallback`. Во время воспроизведения берётся `meta.mediaTime` — время реально показанного кадра. Оно точнее `currentTime` и `timeupdate`, который срабатывает примерно 4 раза в секунду.
- На паузе берётся `currentTime`: после покадрового шага он равен цели seek, и интерфейс обновляется сразу, ещё до отрисовки кадра.
- Дополнительно слушает `play`, `pause`, `seeking`, `seeked`, `ratechange`, `loadedmetadata`, `durationchange`, `emptied`, `ended`.
- Если значения не изменились, возвращается прежний объект, и React не перерисовывает.

Принимает элемент (а не ref), поэтому при смене видео (новый `<video>` с другим `key`) подписки пересоздаются.

## Кто использует

[App](../App.tsx.md): время для таймлайна, транспорта, рисунков и подсветки активного момента.
