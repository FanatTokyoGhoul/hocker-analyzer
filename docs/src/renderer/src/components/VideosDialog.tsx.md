# `components/VideosDialog.tsx` — видео проекта

**Назначение:** управление видео проекта: названия, сдвиги и синхронизация ракурсов. Открывается из ⚙ в [VideoBar](VideoBar.tsx.md).

## Список видео

Для каждого видео поля на [CommitField](CommitField.tsx.md):
- название — непустое (`nonEmpty`), применяется по Enter или потере фокуса;
- сдвиг `offset` в секундах проекта (`parseNumber`, запятая тоже подходит);
- диапазон времени проекта, который покрывает видео (если длительность известна);
- ✕ — убрать видео. Нельзя убрать единственное видео. Рисунки на нём удаляются, моменты остаются.

Изменение сдвига через `updateVideo` сдвигает и рисунки этого видео (см. [projectState](../lib/projectState.ts.md)).

## Синхронизация ракурсов

Пошаговая инструкция:
1. Выбрать опорное видео (`select`) и остановить его на заметном событии (вбрасывание, свисток). Окно показывает, где оно сейчас.
2. Переключиться на другое видео и остановить его на том же событии.
3. Нажать «Синхронизировать» у этого видео.

Для каждого неопорного видео показывается его текущее время. Сдвиг считает `syncOffset` из [videos.ts](../lib/videos.ts.md) по позициям, которые передал [App](../App.tsx.md) (`positions`).
