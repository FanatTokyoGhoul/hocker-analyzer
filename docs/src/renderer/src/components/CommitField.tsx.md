# `components/CommitField.tsx` — общее поле с отложенным применением

**Назначение:** единое поле ввода для всех редактируемых значений: названия, времена, теги, сдвиги, заметка, подписи кнопок, HEX-цвет. Значение применяется по `Enter` или потере фокуса, а не на каждый символ. Так правка не дёргает проект и историю на каждую букву.

Используется в [MomentsPanel](MomentsPanel.tsx.md), [VideosDialog](VideosDialog.tsx.md), [StatsDialog](StatsDialog.tsx.md), [SettingsDialog](SettingsDialog.tsx.md), [DrawMenu](DrawMenu.tsx.md).

## Пропсы

| Пропс | Описание |
|---|---|
| `value` | Текущее значение типа `T` |
| `label` | `aria-label` поля |
| `parse(text)` | Текст → значение. `null` — ввод неверный, поле вернётся к текущему значению |
| `format(value)` | Значение → текст (по умолчанию `String`). Например, `formatTime` для времени |
| `onCommit(value)` | Вызывается только если значение после разбора изменилось |
| `multiline`, `rows` | Многострочное поле (`textarea`) |
| остальные атрибуты `input` | Передаются как есть (`type`, `min`, `max`, `step`, `placeholder`, `className`) |

## Поведение

- **Enter** — применить (потеря фокуса). В многострочном поле Enter переводит строку, применить можно `Ctrl+Enter` или `Cmd+Enter`.
- **Потеря фокуса** — применить.
- **Esc** — отменить правку и вернуть сохранённое значение. Событие **не пускается дальше**, поэтому модальное окно под полем не закрывается.
- Если после применения значение не изменилось (например, его ограничили в [App](../App.tsx.md)), поле показывает сохранённое. Для этого есть `revision`: поле пересинхронизируется даже без изменения значения.
- Пустой текст или неверный ввод откатываются без вызова `onCommit`.

## Вспомогательные разборщики

| Функция | Описание |
|---|---|
| `nonEmpty(t)` | Непустая строка после `trim`, иначе `null` |
| `parseNumber(t)` | Число с запятой или точкой, иначе `null` |

Время разбирает `parseTime` из [time.ts](../lib/time.ts.md), а формат выводит `formatTime`.
