# `components/QuickTagsBar.tsx` — код-окно быстрой разметки

**Назначение:** до девяти кнопок над панелью «Новый момент». Одно нажатие создаёт момент вокруг текущего времени с тегом. Тот же эффект даёт Shift+цифра.

## Что показывает

- Заголовок «Быстрая разметка» и ⚙, который открывает настройки.
- Кнопка на каждый `QuickTag`: подпись и подсказка `⇧N`. В `title` — пояснение: сколько секунд до и после и какой тег.
- Если кнопок нет, показывается подсказка «добавьте их в настройках».

## Поведение

- Кнопки отключены, пока видео не открыто.
- `onMouseDown` отменяет действие по умолчанию, поэтому фокус не уходит с горячих клавиш.
- Сама логика (границы `t − before … t + after`, название «Подпись N», добавление в историю) — в [App](../App.tsx.md), функция `quickTag`.
- Компонент обёрнут в `memo`: не перерисовывается на каждом кадре.

Настройка кнопок — [SettingsDialog](SettingsDialog.tsx.md), хранение — [shared/settings.ts](../../../shared/settings.ts.md).
