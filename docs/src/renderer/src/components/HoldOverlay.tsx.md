# `components/HoldOverlay.tsx`

Плашка сверху по центру во время остановки на кадре с рисунком.

- **Режим «до клавиши»:** текст «Пауза на рисунке — нажмите любую клавишу, чтобы продолжить».
- **Режим таймера:** обратный отсчёт с десятыми долями секунды и тонкая оранжевая полоса, которая убывает до нуля.
- Кнопка **«Продолжить»** есть в обоих режимах.

У плашки `role="status"`: экранный диктор объявит «Пауза на рисунке», но не будет зачитывать каждый шаг отсчёта (он скрыт через `aria-hidden`).

Отсчёт обновляется каждые 100 мс локальным таймером компонента. Само продолжение по таймеру делает [useDrawingStops](../hooks/useDrawingStops.ts.md), а не плашка.
