# `components/BoardDialog.tsx` — схема площадки момента

**Назначение:** тактическая схема момента. Рисуется теми же инструментами, что и на видео, поверх разметки площадки. Схема сохраняется в `Moment.board` и попадает в экспорт перед клипом.

## Как устроено

- Инструменты — `TOOLS` и `Swatch` из [DrawMenu](DrawMenu.tsx.md) без подсветки: на схеме нет «остального поля», которое нужно затемнять.
- [DrawingLayer](DrawingLayer.tsx.md) с `background="rink"`: фон — [разметка площадки](../lib/rink.ts.md).
- Размер схемы — `fitContain` по ширине контейнера и 62% высоты окна, пропорции 200:85.
- Цвета: пресеты, недавние и «любой цвет». Цвет общий с рисованием на видео.
- Изменения — через `onChange(shapes)`, в [App](../App.tsx.md) это действие `setBoard` в общей истории.

## Кнопки

- «Убрать последнюю» и «Очистить» — отключены, если схемы нет.
- «Готово» закрывает окно.
- `Ctrl+Z` отменяет правку схемы: [App](../App.tsx.md) обрабатывает горячие клавиши при открытом окне схемы.
- Подпись, набранная на схеме, сохраняется при закрытии окна, а не теряется.

Открывается кнопкой ▦ в карточке момента ([MomentsPanel](MomentsPanel.tsx.md)).
