# `components/StatsDialog.tsx` — статистика

**Назначение:** таблица моментов по тегам и периодам, периоды времени проекта и выгрузка в CSV. Открывается кнопкой «Статистика». Расчёты — в [stats.ts](../lib/stats.ts.md).

## Периоды

- Начала 2-го, 3-го … периодов во времени проекта. Для каждого: поле времени на [CommitField](CommitField.tsx.md) (формат `m:ss.s`, разбор `parseTime`; значение должно быть больше нуля), «= сейчас» и ✕.
- «+ Период» добавляет текущее время проекта. Повторы и нулевое время не добавляются.
- Момент относится к периоду, в котором он начался.

## Таблица

Строки — теги, «без тега» (если такие есть) и «Всего». Колонки: «Всего», П1…Пn, «Время». Время — сумма длительностей моментов.

Без моментов таблица не показывается, есть подсказка.

## Выгрузка

- «Моменты в CSV» — `моменты.csv`, по одной строке на момент.
- «Статистика в CSV» — `статистика.csv`, строки таблицы.

Файл выбирается через `saveTextFile`. Формат CSV (BOM, `;`, CRLF) описан в [stats.ts](../lib/stats.ts.md).

Стили — [styles/stats.css](../styles/stats.css.md), импортируются в этом файле.
