# `components/Modal.tsx` — общее модальное окно

**Назначение:** каркас для всех диалогов: настройки, видео, схема площадки, экспорт, статистика. Заголовок с кнопками и ✕, содержимое — через `children`.

## Пропсы

| Пропс | Описание |
|---|---|
| `title` | Заголовок и `aria-label` |
| `onClose()` | Закрытие: ✕, Esc, клик по затемнению |
| `className` | Дополнительный класс (размер окна: `.settings-modal`, `.board-modal`, `.export-modal`…) |
| `actions` | Кнопки в шапке рядом с ✕ |
| `locked` | Не закрывать (например, пока идёт экспорт). Кнопка ✕ отключена |

## Поведение

- При открытии фокус переходит в окно; при закрытии возвращается на элемент, где был.
- `Tab` и `Shift+Tab` не выходят за пределы окна (цикл по фокусируемым элементам).
- `Esc` закрывает окно и останавливает всплытие, поэтому его не получает плеер.
- Клик по затемнению закрывает окно, клик внутри — нет.
- `role="dialog"`, `aria-modal="true"`.

Окна рендерятся через `createPortal` в [App](../App.tsx.md): внутрь полноэкранного элемента или в `body`.

Используется в [SettingsDialog](SettingsDialog.tsx.md), [VideosDialog](VideosDialog.tsx.md), [BoardDialog](BoardDialog.tsx.md), [ExportDialog](ExportDialog.tsx.md), [StatsDialog](StatsDialog.tsx.md).
