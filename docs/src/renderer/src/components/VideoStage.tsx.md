# `components/VideoStage.tsx` — область видео

**Назначение:** показывает `<video>` и слой рисования ровно по размеру картинки, даёт зум и перетаскивание кадра, принимает перетаскивание файлов, показывает пустой экран и баннеры.

- Размер контейнера отслеживается через `ResizeObserver`, размер картинки считает `fitContain` ([geometry](../lib/geometry.ts.md)). У `<video>` и [DrawingLayer](DrawingLayer.tsx.md) одинаковый размер.
- `<video key={info.url}>`: при смене файла элемент создаётся заново. Это сбрасывает буферы и заставляет хуки переподписаться.
- `onError` у видео включает баннер «Конвертировать».
- Drag&drop: подсветка рамкой; в `onDropFile` уходит первый файл.
- Нажатие в области видео снимает фокус с полей ввода, чтобы снова работали горячие клавиши.

## Зум

- **Колесо мыши** над кадром: `factor = exp(−deltaY · 0.0015)`, точка под курсором остаётся на месте. Предел ×4 (`MAX_ZOOM`).
- **Перетаскивание** увеличенного кадра: средней кнопкой всегда, левой — когда не рисуем. После перетаскивания клик не ставит видео на паузу (`suppressClick`).
- Сброс: `0` или значок `×N ⟲` в углу кадра. Зум сбрасывается и при смене видео.
- Вид — `transform` элемента `.stage-zoom`, который содержит и видео, и слой рисования. Поэтому рисунки масштабируются вместе с кадром.

## Пропсы-слоты

- `overlay` — баннеры (конвертация, ненайденное видео, кодек, переменная частота).
- `floating` — плавающие элементы поверх видео: [меню рисования](DrawMenu.tsx.md), подпись момента, [плашка остановки](HoldOverlay.tsx.md). Показываются, только когда видео открыто.
- `empty` — экран без видео.
- `hint` — подсказка рисования, например «Поставьте видео на паузу».
- `onDrawStart` пробрасывается в [DrawingLayer](DrawingLayer.tsx.md): начало штриха замораживает таймер остановки на рисунке.
