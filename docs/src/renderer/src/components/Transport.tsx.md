# `components/Transport.tsx` — управление воспроизведением

Одна строка под таймлайном:

- **Слева:** `−N мс`, кадр назад `◀|`, большая круглая ▶/❚❚, кадр вперёд `|▶`, `+N мс`. N берётся из настроек.
- **В центре:** текущее время крупно с миллисекундами, длительность, номер кадра, fps.
- **Справа:**
  - переключатель скорости ×0.25–×1;
  - слайдер 0.1–1;
  - текущая скорость;
  - кнопка полного экрана ⛶ (в полном экране — ⤡ для выхода).

Поле N перенесено в [настройки](SettingsDialog.tsx.md). Компонент только отображает, логика — в колбэках [App](../App.tsx.md).
