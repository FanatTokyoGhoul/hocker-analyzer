# `components/Btn.tsx`

Обёртка над `<button>` с классами `btn`, `btn-<variant>` и `is-active`.

Главное: **кнопка не забирает фокус по клику** (`onMouseDown → preventDefault`). Иначе после клика по «▶» нажатие `Space` «нажимало» бы эту кнопку ещё раз вместо горячей клавиши. Все кнопки интерфейса делаются через `Btn`, кроме цветовых кружков, где то же сделано вручную.
