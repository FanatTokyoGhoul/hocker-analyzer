# `components/Timeline.tsx` — шкала времени

Две дорожки:

1. **Дорожка моментов (сверху):** синие блоки-кнопки. **Клик переходит к началу момента.** Активный момент подсвечен. Оранжевые точки — кадры с рисунками. Минимальная ширина блока 6px, чтобы короткий момент на длинном матче можно было нажать.
2. **Шкала перемотки (снизу):**
   - сыгранная часть закрашена;
   - круглый указатель позиции;
   - штрихованный черновик и метки I/O;
   - нажатие или протягивание перематывает (`setPointerCapture` — перемотка продолжается, даже если курсор ушёл за шкалу);
   - при наведении шкала утолщается.

Дорожки разделены, чтобы клик по моменту не путался с перемоткой.
