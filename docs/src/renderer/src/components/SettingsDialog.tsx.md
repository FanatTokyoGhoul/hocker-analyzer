# `components/SettingsDialog.tsx` — настройки

Модальное окно по кнопке ⚙ в тулбаре. Здесь собрано то, что обычно задают один раз. Изменения применяются и сохраняются сразу, кнопки «Сохранить» нет. Каркас — [Modal](Modal.tsx.md).

| Раздел | Содержимое |
|---|---|
| Воспроизведение | Шаг N для Shift+←/→ (числовое поле) |
| Кнопки быстрой разметки | Редактор `QuickTagsEditor`: подпись, тег, секунды до и после, удаление; «+ Кнопка» (до 9); «Вернуть стандартные» |
| Кадры с рисунками | Остановка: не останавливаться / до нажатия клавиши / на N секунд; поле N; где: при любом просмотре / только в «Проиграть все»; пояснение текущего режима |
| Видео | Параметры открытого файла (размер, кодек, fps с пометкой «переменная», длительность) и «Перекодировать» |
| Файл настроек | Полный путь к `settings.json` и «Показать в папке» |
| Горячие клавиши | Справочник `KEYS` |

## Справочник клавиш

Актуален для v0.3: `Shift + 1–9` — кнопки разметки; `A P L C` и `S Z T D` — инструменты; `Ctrl+Z` и `Ctrl+Shift+Z` — отмена и повтор; колесо мыши и `0` — зум; `Ctrl+S` и `Ctrl+O` — проект. При добавлении клавиши обновите [App](../App.tsx.md) и этот список.

## Поведение

- **Закрытие:** `Esc`, ✕ или клик по затемнению. Пока окно открыто, горячие клавиши плеера не работают.
- **Поля** — [CommitField](CommitField.tsx.md): значение применяется по `Enter` или потере фокуса, `Esc` откатывает. Пока печатаешь «0.5», поле не перескакивает на ограничение после «0».
- **Редактор кнопок:** изменения уходят в `settings.quickTags`, которые санитизирует [shared/settings.ts](../../../shared/settings.ts.md). Пустую подпись поле не принимает.
- Переключатели режимов — `role="radio"` с `aria-checked`.
