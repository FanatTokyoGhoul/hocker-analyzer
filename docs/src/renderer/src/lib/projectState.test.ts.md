# `src/renderer/src/lib/projectState.test.ts`

| Группа | Тест | Что проверяет |
|---|---|---|
| `projectReducer` | сортировка и исправление | Моменты сортируются по `start`, перевёрнутый отрезок 25→10 исправляется, `dirty` взводится |
| | пересортировка и сохранение | Смена границ меняет порядок, `saved` сбрасывает `dirty` |
| | фигуры по кадрам | Две фигуры в пределах полукадра попадают в одну запись, третья — в отдельную. Отмена удаляет последнюю, очистка удаляет запись |
| | отменять нечего | Возвращается тот же объект, `dirty` не меняется |
| История | undo/redo | Отмена и повтор, `dirty` относительно сохранённой версии |
| | пустые правки | В историю не попадают |
| | ограничение | История не длиннее `HISTORY_LIMIT`, самые старые шаги отбрасываются |
| | схема момента | Схема появляется и убирается целиком |
| | восстановление | Восстановленный черновик сразу «грязный», `load` сбрасывает историю |
| Несколько видео | рисунки по видео | Рисунки разделены по видео, удаление видео убирает его рисунки |
| | удаление не первого видео | Убирает только его рисунки |
| | `updateVideo` | Синхронизирует `videoPath` и `fps` первого видео |
| | сдвиг видео | Новый `offset` переносит рисунки этого видео вместе с их кадрами |
| | периоды | Нормализуются |
| Вспомогательные | `momentAt` | Выбор вложенного момента при пересечении |
| | теги | `parseTags`, `collectTags` |
