# `src/renderer/src/lib/paths.ts` — имена файлов

Две функции без зависимостей, чтобы не дублировать разбор пути в компонентах:

| Функция | Описание |
|---|---|
| `fileName(p)` | Имя файла из пути. Понимает и `\` (Windows), и `/` |
| `baseName(p)` | Имя файла без последнего расширения |

Используются в [App](../App.tsx.md) (заголовок окна, имя проекта, сообщения), в [ExportDialog](../components/ExportDialog.tsx.md) (имя готового файла).
