# `src/renderer/src/lib/geometry.ts` — размеры и зум кадра

## Вписывание кадра

`fitContain(container, aspect)` — наибольший прямоугольник с пропорциями видео внутри контейнера, как `object-fit: contain`.

[VideoStage](../components/VideoStage.tsx.md) задаёт этот размер и `<video>`, и canvas рисования. Поэтому canvas совпадает с картинкой до пикселя, и нормированные координаты фигур попадают точно на кадр.

## Цифровой зум

Вид описан тремя числами `ZoomView = { z, tx, ty }`: увеличение и сдвиг в долях кадра (`tx`, `ty` ≤ 0). Так вид переживает смену размера окна.

Видимая точка кадра `p` (0..1) — это `p·z + t`.

| Функция / константа | Описание |
|---|---|
| `NO_ZOOM` | `{ z: 1, tx: 0, ty: 0 }` |
| `MAX_ZOOM` = 4 | Предел увеличения |
| `clampView(v)` | Ограничивает `z` от 1 до 4, сдвиг не даёт показать край за кадром |
| `zoomAt(v, factor, px, py)` | Увеличивает в `factor` раз так, чтобы точка под курсором осталась на месте |
| `panBy(v, dx, dy)` | Сдвигает вид и ограничивает его |

Колесо мыши в [VideoStage](../components/VideoStage.tsx.md) даёт `factor = exp(-deltaY · 0.0015)`. `0` сбрасывает зум.
