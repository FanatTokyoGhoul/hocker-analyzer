# `src/renderer/src/lib/drawingStops.test.ts`

- Времена рисунков собираются со всех моментов и сортируются.
- Для видео с другим сдвигом берутся только его рисунки, в его локальном времени (`drawingTimes` с `offset` и `videoOf`).
- Срабатывание, когда кадр рисунка показан или перешагнут (пропуск кадров 85→95).
- Нет срабатывания, если старт был с кадра рисунка, при движении назад и между рисунками.
- Из нескольких перешагнутых возвращается первый.
