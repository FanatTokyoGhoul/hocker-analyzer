# `src/renderer/src/lib/videos.ts` — несколько видео в проекте

**Назначение:** математика временной шкалы проекта. Проект может содержать несколько видео: периоды подряд или камеры одного эпизода.

## Модель времени

Время моментов и рисунков общее для проекта. Локальное время видео:

```
local = project − offset
```

- **Периоды подряд** («Следующий период»): `offset` равен концу предыдущего видео, время идёт дальше.
- **Ракурсы** («Другой ракурс»): `offset` подбирается синхронизацией по общему событию.

## Функции

| Функция | Описание |
|---|---|
| `videoCovers(v, t, tol)` | Покрывает ли видео время проекта `t`. Если длительность неизвестна, видео покрывает всё после начала |
| `locateTime(videos, t, preferId?, tol)` | Видео для времени `t`: активное, если оно покрывает время (ракурс не переключаем). Иначе видео, начавшееся позже всех до `t`. Иначе первое покрывающее |
| `locateMoment(videos, m, preferId?)` | Видео для момента по его **середине**. Момент, начавшийся ровно на стыке периодов, относится к следующему видео, а не к последнему кадру предыдущего |
| `continuationOffset(videos)` | Сдвиг для «следующего периода»: конец самого позднего видео |
| `syncOffset(ref, refLocal, targetLocal)` | Сдвиг видео `target`, при котором событие на `refLocal` в опорном видео и на `targetLocal` в нём совпадают во времени проекта. Округляется до миллисекунд. Отрицательный сдвиг — камеру включили раньше |
| `nextPeriodLabel(videos)` | Название нового периода: «Период N», где N — на единицу больше самого большого уже существующего «Период N» (первое видео — период 1) |
| `angleLabel(videos)` | Название новой камеры: «Камера 2», «Камера 3» и т.д. по той же схеме |

## Связи

- [App](../App.tsx.md) использует все функции для переключения видео и для «Проиграть все» ([usePlaylist](../hooks/usePlaylist.ts.md)).
- Номера считаются по названиям существующих видео, поэтому удалённый «Период 2» не «возвращает» номер, пока есть «Период 3».
- [stats.ts](stats.ts.md) определяет видео по времени начала момента.
- Тесты — [videos.test.ts](videos.test.ts.md).
