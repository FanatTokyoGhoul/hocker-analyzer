# `src/renderer/src/lib/exportRequest.ts` — сборка запроса экспорта

**Назначение:** превращает выбранные моменты в `ExportRequest` для main. Здесь рисуются все картинки в renderer, потому что Konva и canvas доступны только в нём.

## Область экспорта

`ExportScope`:

| Значение | Что экспортируется |
|---|---|
| `current` | Момент под текущим временем |
| `visible` | Моменты с выбранным тегом (фильтр панели) |
| `all` | Все моменты проекта |

## `buildExportRequest(project, moments, options, meta, preferVideoId, suggestedName)`

1. Каждому моменту назначается видео через `locateMoment`, предпочтение отдаётся активному видео. Моменты вне всех видео пропускаются (`skipped`). Если подходящих нет, функция бросает ошибку.

Параметр `available` — видео, на которых можно искать моменты (по умолчанию все видео проекта). [App](../App.tsx.md) передаёт только открытые видео: моменты на ненайденном видео пропускаются, а рисунки сверяются по полному проекту. Поэтому рисунки первого видео не «переезжают» на другое видео, если первое не найдено.
2. Для каждого видео один раз получаются размер и fps (`meta`). Активное видео берёт их из уже открытого файла.
3. **Размер выходного кадра** — размер первого подходящего видео, округлённый до чётного (минимум 16).
4. Для каждого клипа:
   - `start` и `end` — локальное время (`момент − offset`, не меньше 0);
   - `overlays` — рисунки этого видео внутри отрезка, в локальном времени, PNG в размере кадра видео. Только при `holdSeconds > 0`;
   - `captionPng` — подпись в размере выходного кадра, если включены подписи;
   - `boardPng` — схема площадки, если включены схемы и у момента есть `board`, и при `holdSeconds > 0`.

`captionSubtitle(m)` собирает подпись из тегов (`#гол #бросок`) и первой строки заметки через « · ».

Тесты — [exportRequest.test.ts](exportRequest.test.ts.md).

## Опции

`ExportOptions`: `mode` (`single` / `separate`), `holdSeconds`, `captions`, `boards`.
