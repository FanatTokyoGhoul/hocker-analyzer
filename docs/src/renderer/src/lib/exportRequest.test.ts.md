# `src/renderer/src/lib/exportRequest.test.ts`

Картинки рисует Konva в браузере, поэтому модуль `shapeRender` подменяется: функции возвращают строку с числом фигур и размером. Тесты проверяют, что и в каком размере просят нарисовать.

| Тест | Что проверяет |
|---|---|
| подзаголовок подписи | Теги с `#` и первая строка заметки через « · » |
| клипы в локальном времени | Каждый клип идёт в локальном времени своего видео. Рисунки берутся только с этого видео и только из отрезка момента |
| без стоп-кадров | При `holdSeconds = 0` нет ни рисунков, ни схемы. Подпись — по желанию |
| недоступное видео | Рисунки первого видео не переезжают на другое, если первое не найдено (параметр `available`) |
| нет подходящих моментов | Ошибка «Нет моментов, которые попадают в видео проекта» |

Код — [exportRequest.ts](exportRequest.ts.md).
