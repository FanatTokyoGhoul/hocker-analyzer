# `src/renderer/src/lib/drawingStops.ts` — где останавливаться на рисунках

Чистые функции для [useDrawingStops](../hooks/useDrawingStops.ts.md).

| Функция | Описание |
|---|---|
| `drawingTimes(moments, videoId?, offset, videoOf?)` | Локальные времена рисунков **одного видео** по возрастанию: время проекта минус `offset`. Рисунки без `videoId` относятся к первому видео (через `videoOf`) |
| `findCrossedDrawing(times, prevFrame, curFrame, fps)` | Первый рисунок, у которого `prevFrame < кадр ≤ curFrame`, иначе `null` |

[App](../App.tsx.md) передаёт `drawingTimes` для активного видео, поэтому рисунки другого видео на нём не останавливают просмотр.

**Почему «перешагнул», а не «равен»:** на скорости ×1 при нагрузке или при пропуске кадров нужный кадр может так и не показаться. Проверка пересечения ловит рисунок в любом случае.

**Почему `prevFrame < кадр` строго:** если воспроизведение началось прямо с кадра рисунка (например, после остановки на нём), повторной остановки не будет.
