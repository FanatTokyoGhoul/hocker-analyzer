# `src/renderer/src/lib/projectState.ts` — состояние проекта (редьюсер с историей)

**Назначение:** всё изменяемое состояние проекта: проект, путь к файлу, сохранённая версия, история правок. Меняется только через `projectReducer`. В [App](../App.tsx.md) подключён через `useReducer`.

## Состояние

```ts
type ProjectState = {
  project: Project | null
  projectPath: string | null
  savedProject: Project | null   // последняя сохранённая версия
  dirty: boolean                 // project !== savedProject
  past: HistoryEntry[]           // шаги для Ctrl+Z
  future: HistoryEntry[]         // шаги для Ctrl+Shift+Z / Ctrl+Y
}
```

`HistoryEntry` — `{ project, label }`. `label` — название правки для тоста: «Отменено: рисунок».

## История

- Каждая правка кладёт предыдущий проект в `past`. Лимит — `HISTORY_LIMIT` = 200 шагов.
- Новая правка очищает `future`.
- `undo` и `redo` переносят проект между стеками. Они не добавляют запись в историю.
- **`dirty` относительно сохранённой версии:** undo до сохранённого состояния снимает «•».
- Пустые правки (ничего не изменилось) возвращают тот же объект состояния и в историю не попадают.

`undoLabel(s)` и `redoLabel(s)` возвращают названия следующих шагов для подсказок в тулбаре.

## Действия (`ProjectAction`)

| `type` | Эффект |
|---|---|
| `new` | Проект для только что открытого видео. `savedProject` = проект, `dirty = false`, история пустая |
| `load` | Проект из файла или черновика. История сбрасывается. `restored: true` делает проект «грязным» (черновик ещё не сохранён) |
| `saved` | Новый путь и `savedProject`. `dirty` пересчитывается |
| `addVideo` / `updateVideo` / `removeVideo` | Видео проекта. `updateVideo` синхронизирует `videoPath` и `fps` с первым видео. Если меняется `offset`, рисунки этого видео сдвигаются на ту же величину: они привязаны к кадрам видео. `removeVideo` удаляет рисунки этого видео; нельзя удалить единственное видео |
| `addMoment` | Перевёрнутый отрезок исправляется, список сортируется |
| `updateMoment` | Частичное изменение: название, границы, теги, заметка. Пересортировка только при смене границ. Пустая заметка удаляется |
| `deleteMoment` | Удалить момент |
| `addShape` / `undoShape` / `clearShapes` | Фигуры на кадре `time` видео `videoId` момента `momentId` |
| `setBoard` | Схема площадки момента. Пустой список удаляет поле `board` |
| `setPeriods` | Начала периодов, нормализуются. Пустой список удаляет поле `periods` |
| `undo` / `redo` | Шаг истории |

## Рисунки по кадрам и видео

- `drawingVideoId(project, d)` — `d.videoId`, а если его нет, то первое видео. Так работают рисунки проектов v1.
- `findDrawingIndex(project, m, time, tolerance, videoId)` ищет рисунок того же видео в пределах `tolerance`. [App](../App.tsx.md) передаёт полукадр.
- Если после правки фигур не осталось, запись `drawings` удаляется.

## Вспомогательные функции

| Функция | Описание |
|---|---|
| `sortMoments` | По `start`, затем по `end` |
| `momentAt(moments, t, tol)` | Момент, содержащий время `t`. При пересечении — начавшийся позже, то есть самый «вложенный» |
| `collectTags` | Все теги проекта без повторов, отсортированные по-русски |
| `parseTags("пас, гол,, гол")` | → `['пас', 'гол']` |
