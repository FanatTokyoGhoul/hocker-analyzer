# `src/renderer/src/lib/stats.ts` — статистика и CSV

**Назначение:** подсчёт моментов по тегам и периодам и выгрузка в CSV. Чистые функции, покрыты тестами ([stats.test.ts](stats.test.ts.md)).

## Периоды

`periods` — начала 2-го, 3-го … периодов во времени проекта. Момент относится к периоду, в котором **начался**. Граница относится к следующему периоду.

| Функция | Описание |
|---|---|
| `periodOf(time, periods)` | Номер периода с 1 |
| `normalizePeriods(list)` | Только конечные числа больше нуля, по возрастанию, без повторов |

## Таблица статистики

`tagStats(moments, periods)` возвращает строки `StatsRow` (`kind`, `label`, `count`, `duration`, `perPeriod`):

- строка на каждый тег;
- «без тега» — только если есть моменты без тегов;
- «Всего» — в итоге момент с двумя тегами считается один раз.

`duration` — сумма длительностей, `perPeriod` — количество по периодам.

## CSV

Общие правила `toCsv`:
- UTF-8 с BOM, чтобы Excel открыл кириллицу правильно;
- разделитель `;`, перевод строки CRLF;
- дробные числа с запятой (`1,5`);
- поля в кавычках, если в них есть `;`, кавычка или перевод строки; кавычки удваиваются;
- поле, начинающееся с `=`, `+`, `-`, `@`, табуляции или возврата каретки, получает `'` спереди, чтобы Excel не выполнил формулу;
- поля с табуляцией тоже берутся в кавычки.

| Функция | Колонки |
|---|---|
| `momentsCsv(moments, videos, periods)` | №, Название, Теги, Начало, Конец, Длительность, с, Период, Видео, Заметки, Рисунков |
| `statsCsv(rows, periodCount)` | Тег, Всего, П1…Пn, Время, с |

Колонка «Видео» определяется так же, как при просмотре и экспорте: через `locateMoment` из [videos.ts](videos.ts.md). Если видео одно, оно указывается всегда. Колонка «Период» берётся из нормализованных периодов.
