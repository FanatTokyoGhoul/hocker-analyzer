# `src/renderer/src/App.tsx` — корневой компонент

**Назначение:** связывает всё вместе. Хранит состояние, реализует сценарии пользователя, назначает горячие клавиши и собирает экран.

## Состояние

| Что | Где |
|---|---|
| Проект, путь, `dirty`, история правок | `useReducer(projectReducer)` — [projectState](lib/projectState.ts.md) |
| Видео проекта, активное видео, длительности, позиции | `useState`; `missing` — пути видео, которые не нашлись (хранятся по пути, не по id); `positions` — `useRef`, где стояло каждое видео при переключении; `pendingSeek` — перемотка, которую выполнить, когда загрузится новое видео |
| Загруженное видео | `loaded` = `{ id, path, info }`. Результат ffprobe привязан к видео и к пути. Пока выбранное видео грузится, `info` равен `null`, поэтому время и рисунки не попадают не в то видео |
| Настройки (шаг N, остановки, цвет, недавние, кнопки разметки) | [useSettings](hooks/useSettings.ts.md) |
| `<video>` и секция `.viewer` | `useState` + callback-ref, чтобы хуки перезапускались при смене элементов |
| Время и пауза | [useVideoClock](hooks/useVideoClock.ts.md) |
| «Проиграть все» | [usePlaylist](hooks/usePlaylist.ts.md) |
| Остановки на рисунках | [useDrawingStops](hooks/useDrawingStops.ts.md); `enabled` = «при любом просмотре» или идёт плейлист |
| Полный экран и скрытие панелей | [useFullscreen](hooks/useFullscreen.ts.md), [useIdle](hooks/useIdle.ts.md) |
| Черновик для восстановления | `recovery` — найденный черновик, `recoveryResolved` — решено ли, писать ли новый |
| Диалог | `dialog`: `settings`, `stats`, `export`, `videos` или `board` с id момента |
| Зум, инструмент, фильтр по тегу, черновик момента, меню рисования, ошибки, тосты | `useState` |
| Экспорт | `exportBusy`, `exportProgress`, `exportResult`, `exportError` |

## Время проекта и локальное время

- `offset` — сдвиг активного видео. `ptime = clock.time + offset` — **время проекта**, по нему работают моменты и рисунки.
- Все вызовы к `<video>` (перемотка, `currentTime`) идут в **локальном** времени. Переход из времени проекта в локальное делается вычитанием `offset`.
- Видео, которое покрывает время, выбирает [videos.ts](lib/videos.ts.md). Моменты на других видео переключают вкладку.

## Сценарии

- **Воспроизведение.**
  - `seek(t)` — любая ручная перемотка; выключает плейлист.
  - `togglePlay` — во время остановки на рисунке продолжает.
  - `stepFrame`, `stepBy` (N из настроек), `setRate`.
- **Видео и проект.**
  - `openVideo` / `dropVideo` — новый проект из одного видео;
  - `addVideo('next' | 'angle')` — период или ракурс. Период получает `offset` = конец предыдущего, ракурс — `offset` 0 до синхронизации. Названия — `nextPeriodLabel` и `angleLabel` из [videos.ts](lib/videos.ts.md);
  - `selectVideo`, `removeVideo`, `syncVideos` (сдвиг по позициям опорного видео). Смена `offset` переносит рисунки этого видео (см. [projectState](lib/projectState.ts.md));
  - `relocateVideo` — указать файл для ненайденного видео. Моменты и рисунки сохраняются;
  - `openProject`, `saveProject`, `convertVideo`.
  - `projectForDisk` подставляет длительности и fps открытых видео перед записью.
- **Черновик.** Через 3 с после правки (`RECOVERY_DELAY_MS`) при `dirty` вызывается `writeRecovery`. Чистый проект удаляет черновик. Пока баннер восстановления не решён, новый черновик не пишется, чтобы не затереть найденный.
- **История.** `undo` и `redo` показывают тост «Отменено: …» / «Повторено: …». Кнопки ↶ ↷ в шапке.
- **Моменты.**
  - `markIn` / `markOut` / `addMoment`;
  - `quickTag(q)` — кнопка быстрой разметки: момент `[t − before; t + after]` в границах видео, название «Подпись N» (N — порядковый номер среди моментов с тегом), тост с подсказкой Ctrl+Z;
  - `selectMoment` — переход к началу; на другом видео переключает его;
  - `playOne`, `playAll`, `updateMoment`, `setBoundToNow`, `deleteMoment` (с подтверждением), `openBoard`.
- **Рисование.**
  - Фигура сохраняется на середину текущего кадра активного видео (`videoId`).
  - Цвет попадает в «недавние» (`pushRecentColor`) только когда ею действительно нарисовали.
  - Открытие меню рисования, схемы и настроек, а также начало штриха вызывают `stops.freeze()`.
- **Экспорт.** `runExport` собирает запрос через [exportRequest](lib/exportRequest.ts.md), сохраняет результат и показывает его в диалоге. Моменты вне открытых видео пропускаются и сообщаются в ошибке.
- **Статистика.** Диалог получает моменты, видео и периоды проекта. Периоды пишутся через `setPeriods`.

## Горячие клавиши

Порядок обработки:

1. Пока открыт диалог, управление видео не работает. Исключение: `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` в окне схемы площадки (общая история).
2. Во время остановки «до клавиши» клавиши со своим действием (`Ctrl/Cmd`+…, стрелки, `I`/`O`, `Enter`, цифры, инструменты, `F`, `Esc`) выполняют его, не снимая остановку. Стрелки перематывают и этим её снимают. Любая другая клавиша продолжает просмотр. Одиночные модификаторы игнорируются.
3. Обычные клавиши:

| Клавиша | Действие |
|---|---|
| `Space` | Пауза / продолжение (во время остановки на рисунке — продолжить) |
| `←` / `→`, `Shift`+`←` / `→` | Кадр, ±N мс |
| `I` / `O`, `Enter` | Границы и добавление момента |
| `Shift`+`1`–`9` | Кнопка быстрой разметки с этим номером |
| `1`–`4` | Скорость ×0.25 / ×0.5 / ×0.75 / ×1 |
| `A` `P` `L` `C` `S` `Z` `T` `D` | Инструмент: движение, пас, линия, круг, подсветка, зона, текст, от руки. Меню не открывается |
| `0` | Сбросить зум |
| Колесо мыши над кадром | Зум (до ×4), см. [VideoStage](components/VideoStage.tsx.md) |
| `Esc` | Закрыть меню рисования и выключить инструмент (выход из полного экрана делает браузер) |
| `F` | Полный экран |
| `Ctrl+Z`, `Ctrl+Shift+Z` / `Ctrl+Y` | Отмена и повтор правок |
| `Ctrl+S` / `Ctrl+Shift+S` / `Ctrl+O` | Сохранить, сохранить как, открыть проект |

Клавиша `Z` без `Ctrl` — инструмент «Зона», `Ctrl+Z` — отмена. Клавиши плеера (`PLAYER_KEYS`) не снимают остановку «до клавиши».

## Раскладка

```
toolbar:  🏒 Hockey Analyzer | файл • ↶ ↷ | Открыть видео  Открыть проект  Статистика  Экспорт  Сохранить как…  [Сохранить]  ⚙
viewer:   VideoBar (видео проекта: вкладки, + Видео, ⚙)
          VideoStage (видео + рисунки + зум + меню рисования + подпись момента + плашка остановки + баннеры)
          controls: Timeline (моменты / перемотка) + Transport (… ⛶)
panel:    MomentsPanel (быстрая разметка, новый момент, список)
```

В полноэкранном режиме `.controls` лежат поверх видео с градиентом. Во время воспроизведения через 2.5 с без движения мыши панели, ✎-кнопка и курсор скрываются.

Диалоги (`createPortal`) рендерятся внутрь полноэкранного элемента, иначе их не видно. Тосты — там же. Поэтому «Сохранено» и ошибки видны и в полноэкранном режиме. Открытие диалога замораживает таймер остановки на рисунке.

Баннеры над видео (по приоритету): черновик для восстановления → конвертация → видео не найдено (с кнопкой «Указать видео») → кодек не поддерживается → переменная частота кадров.
