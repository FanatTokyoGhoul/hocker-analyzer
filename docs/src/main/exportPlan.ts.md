# `src/main/exportPlan.ts` — команды ffmpeg для экспорта

**Назначение:** чистые функции сборки команд экспорта. Нет Electron, нет файловой системы, поэтому всё покрыто тестами ([exportPlan.test.ts](exportPlan.test.ts.md)). Запуск процессов — в [export.ts](export.ts.md).

## Как строится клип

Клип режется на куски (`planPieces`):

- **`play`** — обычное воспроизведение отрезка (`trim` + `setpts`);
- **`freeze`** — стоп-кадр рисунка.

Стоп-кадр берётся окном в один кадр, центрированным на времени рисунка. Так выбирается ближайший кадр независимо от выравнивания исходного файла по сетке кадров. Рисунки вне клипа игнорируются, на границах зажимаются.

Для каждого стоп-кадра:
1. кадр растягивается `tpad` (клонирование последнего кадра) на `holdSeconds`;
2. PNG рисунка накладывается `overlay` с `repeatlast=1`. Наложение идёт **до** масштабирования, на родном размере кадра;
3. звук на время стоп-кадра — тишина.

**Схема площадки** (если есть) показывается перед клипом на `holdSeconds`, с тишиной.

**Подпись** (название, теги, заметка) накладывается на первые `CAPTION_SECONDS` = 3 с. Если перед клипом есть схема, окно подписи сдвигается на `holdSeconds`.

Все куски приводятся к одному размеру и fps (`scale` + `pad` + `fps` + `yuv420p`), звук — к 48 кГц стерео. Если у видео нет аудио, используется `aevalsrc` с тишиной. Куски склеиваются `concat`.

## Функции

| Функция | Описание |
|---|---|
| `planPieces(clip, hold)` | Режет клип на `play`/`freeze` |
| `expectedClipDuration(clip, hold)` | Длительность готового клипа: отрезок + стоп-кадры + схема |
| `buildClipJob(opts)` | Аргументы ffmpeg, текст фильтр-графа и ожидаемая длительность. Кодеки: H.264 `veryfast`, CRF 20; AAC 160k; `+faststart`; `-progress pipe:1` |
| `sanitizeFileName(title)` | Убирает символы, недопустимые в Windows и Linux; обрезает до 80 символов; `con`, `nul` и т.п. получают префикс `_` |
| `clipFileName(i, total, title)` | `NN Название.mp4`, ширина номера зависит от числа клипов |
| `buildConcatList(paths)` | Список для concat: кавычки экранируются как `'\''` |
| `buildConcatArgs(list, out)` | `-c copy` без перекодирования |

## На что обратить внимание

- Порядок оверлея важен: на единственном кадре фильтры кадров без `fps` и `tpad` не отдают результат, поэтому растягивание идёт до наложения.
- `CAPTION_SECONDS` и `SAMPLE_RATE` меняются только здесь.
