# `src/main/exportPlan.test.ts` — тесты команд экспорта

| Группа | Что проверяет |
|---|---|
| `planPieces` | Без рисунков — один кусок до конца. Один рисунок делит клип на воспроизведение, стоп-кадр и продолжение. Два рисунка сортируются, индекс сохраняется. Рисунки вне клипа игнорируются, на границах зажимаются. При `holdSeconds = 0` стоп-кадров нет |
| Длительность | Клип + стоп-кадры × hold + схема |
| `buildClipJob` | Аргументы: поиск до `-i`, whitelist, скрипт фильтра, кодеки. С аудио — `aresample`, без аудио — `aevalsrc`. Рисунок — оверлей до масштабирования, второй PNG-вход. Подпись только первые 3 с, со схемой окно сдвигается на hold. Без подписи и схемы лишних входов нет |
| Имена файлов | Недопустимые символы и длина. Нумерация клипов |
| `concat` | Кавычки экранируются. Потоки копируются без перекодирования |

Тесты — чистые, без ffmpeg. Реальный рендер проверяет e2e-сценарий 17 в [smoke.mjs](../../tests/e2e/smoke.mjs.md).
