# `src/main/probe.test.ts` — тесты main-логики

Юнит-тесты (vitest) для [probe.ts](probe.ts.md) и `parseRange` из [media.ts](media.ts.md).

| Блок | Что проверяет |
|---|---|
| `ffprobe` | `parseFrameRate` (дробные, нулевые, отсутствующие значения). Конвертация требуется для HEVC, H.264 High 10 и AC-3 и не требуется для обычного H.264. Ошибка без видеопотока. Разбор `-progress` |
| `Range` | Все формы заголовка: `0-`, `10-20`, выход за конец файла, суффикс `-10`, начало за концом файла, неверная единица |
| `переменная частота кадров` | Реальные значения с телефона (`88920000/2971379` против `30/1`) → VFR; `30000/1001` с обеих сторон → не VFR |

Запуск: `npm test`.
