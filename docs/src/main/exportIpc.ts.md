# `src/main/exportIpc.ts` — IPC экспорта клипов

**Назначение:** регистрирует каналы экспорта и отвечает за диалоги выбора файла или папки. Сам рендеринг делает [export.ts](export.ts.md).

## Каналы

| Канал | Тип | Что делает |
|---|---|---|
| `export:clips` | `invoke` | Проверяет запрос через `validateExportRequest`, проверяет каждое видео (`isAllowedMedia`), показывает диалог и запускает `runExport` |
| `export:progress` | `send` из main | Прогресс `{ ratio, clip, clips }` отправляется отправителю запроса |
| `export:cancel` | `invoke` | `cancelExport()` |

## Проверка путей

Для каждого клипа путь приводится к абсолютному (`resolve`), проверяется по `isAllowedMedia` и **в запрос записывается именно проверенный путь**. Так ffmpeg получает ровно тот файл, который разрешили, даже если строка в запросе была другой.

## Диалоги

- **`single`** — диалог «сохранить как» с именем `suggestedName.mp4`. По умолчанию открывается папка исходного видео первого клипа.
- **`separate`** — диалог выбора папки (с возможностью создать новую). Файлы получают имена `NN Название.mp4`.

Если окно не найдено, диалог открывается без привязки к окну.

## Что возвращается

`{ paths }` — созданные файлы. Их пути добавляются в `revealablePaths` через `onExported`, чтобы кнопка «Показать в папке» работала ([index.ts](index.ts.md)). Отмена диалога возвращает `null`.

## Связи

- Регистрируется из `registerIpc()` в [index.ts](index.ts.md).
- Тип запроса — `ExportRequest` в [shared/types.ts](../shared/types.ts.md).
- Имена файлов — `sanitizeFileName` из [exportPlan.ts](exportPlan.ts.md).
