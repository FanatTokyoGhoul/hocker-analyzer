# `src/main/recovery.ts` — черновик для восстановления

**Назначение:** хранит последнюю несохранённую работу в `recovery.json` в профиле приложения (`app.getPath('userData')`, то есть `~/.config/ftg/hockey-analyzer/recovery.json` в Linux). Если приложение упало или его закрыли без сохранения, при следующем запуске [App](../renderer/src/App.tsx.md) предложит восстановить работу.

## Когда пишется и удаляется

| Событие | Что происходит |
|---|---|
| Проект несохранён и изменился | Рендерер через 3 с после последней правки вызывает `recovery:write` (`RECOVERY_DELAY_MS`) |
| Проект сохранён | `project:save` в [index.ts](index.ts.md) удаляет черновик |
| Проект чист (`dirty = false`) | Рендерер вызывает `writeRecovery(null)` |
| «Выйти без сохранения» при закрытии окна | `clearRecoverySync()` — синхронно, пока окно закрывается |
| «Удалить» в баннере восстановления | Рендерер вызывает `writeRecovery(null)` |

## API

| Функция | Описание |
|---|---|
| `recoveryPath()` | Путь к `recovery.json` |
| `writeRecovery(data \| null)` | Записи идут строго по очереди (цепочка промисов). Запись атомарная: `.tmp` + `rename`. `null` — удалить файл. Ошибки пишутся в консоль и не роняют приложение |
| `clearRecoverySync()` | Синхронное удаление для обработчика закрытия окна. Одновременно включает флаг `discarded` |
| `readRecovery()` | Дожидается текущей записи, читает файл и проверяет проект через `parseProject`. Битый или отсутствующий файл → `null` |

## Флаг `discarded`

После «Выйти без сохранения» процесс уже закрывается, но запоздавшие записи из рендерера могли бы вернуть черновик. Поэтому после `clearRecoverySync()` любая запись превращается в удаление файла. Флаг сбрасывается только перезапуском процесса.

Проект в черновике сериализуется тем же `serializeProject`, что и при сохранении, поэтому формат совпадает с файлом проекта (версия 2).

## Доверие к пути проекта

`projectPath` в черновике запоминается только если путь уже доверенный (выбран через диалог в этой сессии). Иначе черновик стал бы способом записать файл в произвольное место. Путь на сетевой шаре не принимается.

## Связи

- Вызывается из обработчиков `recovery:write`, `recovery:read` и `project:save` в [index.ts](index.ts.md). Вход `recovery:write` ограничен 50 МБ JSON.
- Тип `Recovery` — в [shared/types.ts](../shared/types.ts.md).
- Проверка проекта — [shared/project.ts](../shared/project.ts.md).
