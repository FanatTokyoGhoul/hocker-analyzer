# `src/main/settings.test.ts`

Тесты хранилища `settings.json`. Модуль `electron` подменяется (`vi.mock`): `app.getPath` возвращает временную папку.

- Без файла — настройки по умолчанию. Сохранение не пишет файл сразу, а через ~300 мс, и в файле есть `version: 1` и новые значения.
- Битый JSON переименовывается в `settings.json.bak`, используются умолчания.
- Мусор от рендерера (отрицательный шаг, неизвестный режим, `javascript:` вместо цвета, лишние поля) не попадает в файл.
