# Hockey Analyzer

Десктоп-приложение (Windows / macOS / Linux) для разбора любительских хоккейных матчей:
открыть видео, разметить моменты, просмотреть их подряд, порисовать поверх кадра и выгрузить клипы.

## Запуск

```bash
npm install
npm run dev        # режим разработки с HMR
npm test           # юнит-тесты (vitest)
npm run test:e2e -- <video.mp4> [hevc.mp4]   # сквозной прогон приложения (playwright)
npm run dist:linux # .AppImage и .deb в dist/ (dist:win → .exe, dist:mac → .dmg)
```

> ffmpeg-static при `npm install` скачивает бинарник под **текущую** ОС, поэтому каждую
> платформу нужно собирать на ней самой. Для этого есть `.github/workflows/build.yml`
> (матрица ubuntu / windows / macos, запускается по тегу `v*` или вручную).

## Что умеет

### Просмотр и разметка

| Функция | Как |
|---|---|
| Открыть видео | кнопка, перетаскивание файла в окно |
| Несколько видео в проекте | вкладки над плеером: «+ Следующий период» (тайм продолжается) или «+ Другой ракурс» (синхронизация по событию). Моменты идут в общем времени проекта |
| Пауза / продолжение | `Space`, клик по видео |
| Шаг на кадр | `←` / `→` (fps определяется ffprobe) |
| Шаг на N мс | `Shift`+`←` / `→`, N — в настройках ⚙ (по умолчанию 100) |
| Замедление 0.1–1 | слайдер, `1`–`4` → ×0.25 / ×0.5 / ×0.75 / ×1 |
| Разметка момента | `I` начало, `O` конец, название + теги, `Enter` |
| Быстрая разметка | кнопки в панели или `Shift`+`1`–`9`: один момент вокруг текущего времени с тегом («Гол», «Бросок», «Потеря»…). Кнопки настраиваются, до 9 |
| Список моментов | клик по карточке или блоку на таймлайне — переход к началу; ✎ — правка названия, границ, тегов и заметки; фильтр по тегу |
| Заметки | поле «заметка» у момента; показывается в карточке и подписью на видео во время «Проиграть все» |
| Проиграть все подряд | кнопка в панели (учитывает фильтр и переходит между видео) |
| Отмена и повтор | `Ctrl+Z` / `Ctrl+Shift+Z` (или `Ctrl+Y`), кнопки ↶ ↷ в шапке. История — до 200 шагов |
| Автосохранение черновика | через 3 с после правки работа пишется в `recovery.json`. После сбоя при запуске предлагается «Восстановить» или «Удалить» |

### Рисование

| Функция | Как |
|---|---|
| Меню рисования | полупрозрачная кнопка ✎ на видео; любой RGB-цвет (палитра, пипетка, HEX, недавние) |
| Инструменты | `A` движение (стрелка), `P` пас (пунктирная стрелка), `L` линия, `C` круг, `S` подсветка игрока (затемняет всё вокруг), `Z` зона (многоугольник кликами), `T` текст, `D` от руки |
| Выход из инструмента | `Esc`, повторный клик по инструменту |
| Отмена и очистка | `Ctrl+Z` или «Отменить» в меню, «Очистить кадр» |
| Зум кадра | колесо мыши над видео (до ×4), перетаскивание средней кнопкой или левой вне рисования; `0` или значок в углу — сброс |
| Остановка на рисунках | в настройках: до нажатия клавиши или на N секунд; при любом просмотре или только в «Проиграть все» |
| Схема площадки | у момента своя схема (▦ в карточке): те же инструменты поверх разметки хоккейной площадки |

### Статистика и экспорт

| Функция | Как |
|---|---|
| Статистика | кнопка «Статистика»: моменты по тегам, «без тега», итог; разбивка по периодам (начала задаются во времени проекта) |
| CSV | «Моменты в CSV» и «Статистика в CSV». Кодировка UTF-8 с BOM, разделитель `;`, открывается в Excel |
| Экспорт клипов | кнопка «Экспорт»: текущий момент, с тегом или все. Одним файлом-подборкой или отдельными файлами в папку |
| Рисунки в видео | каждый рисунок — стоп-кадр на заданное время (по умолчанию как остановка в плеере), затем видео продолжается. Подпись (название, теги) в начале клипа, схема площадки перед клипом — по выбору |
| Прогресс и отмена | экспорт идёт в фоне, его можно отменить |

### Файлы и настройки

| Функция | Как |
|---|---|
| Проект | `Ctrl+S` / `Ctrl+Shift+S` / `Ctrl+O`, JSON (формат v2; старые проекты v1 открываются как одно видео) |
| Полный экран | `F` или ⛶; во время воспроизведения панели прячутся |
| Настройки | ⚙: шаг N, кнопки быстрой разметки, остановки на рисунках, перекодирование видео, справочник клавиш |
| Файл настроек | `settings.json` в `~/.config/ftg/hockey-analyzer/` (Windows: `%APPDATA%\ftg\hockey-analyzer\`, macOS: `~/Library/Application Support/ftg/hockey-analyzer/`) |
| HEVC и прочее | ffprobe определяет кодек; если Chromium не воспроизведёт — предлагается конвертация в H.264 с `-g 10` |
| Видео не найдено | если файл переехал, баннер «Указать видео» сохраняет моменты и рисунки |

Горячие клавиши работают по физическим клавишам, поэтому и в русской раскладке.

## Устройство

```
src/
  shared/        типы (Project v2, Moment, Shape…), валидация JSON проекта и настроек
  main/          процесс Electron: окно, протокол media://, ffprobe/ffmpeg, IPC,
                 экспорт клипов (export*.ts), черновик (recovery.ts), настройки
  preload/       contextBridge → window.api
  renderer/src/
    lib/         чистая логика, покрыта тестами: шаг кадра, редьюсер проекта с историей,
                 решение плейлиста, несколько видео (videos.ts), статистика и CSV (stats.ts),
                 сборка экспорта, отрисовка фигур и площадки (shapeRender.ts, rink.ts)
    hooks/       useVideoClock (requestVideoFrameCallback), usePlaylist, useDrawingStops, useHotkeys
    components/  VideoStage + DrawingLayer (konva), VideoBar, MomentsPanel, QuickTagsBar,
                 диалоги на базе Modal: SettingsDialog, VideosDialog, BoardDialog, ExportDialog, StatsDialog
    styles/      стили окон, которые живут рядом с компонентами (stats.css)
tests/e2e/       playwright-прогон собранного приложения (сценарии 1–20)
docs/            документация по каждому файлу, структура повторяет репозиторий (см. docs/README.md)
```

Ключевые решения:

- **Видео через протокол `media://`** с поддержкой HTTP Range (без него не работает перемотка).
  Отдаются только файлы, которые пользователь сам открыл.
- **Покадровый шаг** ставит `currentTime` в середину целевого кадра — так seek всегда попадает в нужный
  кадр даже при 29.97 fps и округлённых таймстемпах.
- **Время проекта.** Моменты и рисунки хранят общее время проекта. Локальное время видео — это время проекта
  минус сдвиг видео (`offset`), поэтому периоды подряд и несколько камер работают с одной шкалой.
- **«Проиграть все»** — конец отрезка ловится в `requestVideoFrameCallback` по `mediaTime`
  показанного кадра; решение «продолжать / следующий / пауза на рисунке / стоп» — чистая функция `decidePlaylistStep`.
  Переход между видео идёт через то же решение.
- **Рисунки** хранятся в координатах 0..1 относительно кадра, привязаны к моменту, видео и времени кадра
  (`drawings: [{ time, shapes, videoId? }]`), поэтому не зависят от размера окна. Схема площадки
  хранится у момента отдельно (`board`) в координатах площадки 200×85.
- **Экспорт** — рендерер рисует PNG тем же кодом, что и экран; main собирает клипы ffmpeg. Подборка
  склеивается без перекодирования (`-c copy`).
- **Сохранение** атомарное (временный файл + rename). Если видео переместили вместе с проектом, оно ищется рядом с JSON.
  Черновик для восстановления пишется отдельно и удаляется при сохранении.
